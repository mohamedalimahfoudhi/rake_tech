# Tennis Club Management System

A comprehensive web application built with Symfony for managing tennis club operations, events, and bookings.

## 🎾 Overview

This system provides a complete solution for tennis clubs to manage their facilities, events, and member interactions. Features include court reservations, event management, ticket booking, and equipment rental tracking.

## 🚀 Key Features

- **Court Management**
  - Real-time court availability
  - Advanced booking system
  - Court maintenance tracking
  - Paddel and tennis court support

- **Event Organization**
  - Tournament creation and management
  - Ticket sales and management
  - Participant registration
  - Automated status updates

- **Member Management**
  - User profiles and authentication
  - Booking history
  - Equipment rental tracking
  - Role-based access control

## 🛠 Installation

1. Clone the repository:
```bash
git clone https://github.com/yourusername/tennis-club-management.git
```

2. Install dependencies:
```bash
composer install
```

3. Configure your database in `.env`:
```env
DATABASE_URL="mysql://username:password@127.0.0.1:3306/chleghem"
```

4. Create database and run migrations:
```bash
php bin/console doctrine:database:create
php bin/console doctrine:migrations:migrate
```

5. Start the development server:
```bash
symfony server:start
```
